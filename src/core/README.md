# afinah Core Engine

This is the first modular backend foundation for afinah's natural-language Life Operating System.

## Design rules
- User agency is sovereign.
- Sensitive domains activate only with explicit user consent.
- Legal, financial and wellness outputs require source-grounding and clear limits.
- ADHD support personalizes productivity strategies; it does not diagnose.
- Uploaded text/PDF/database content enters through a normalized ingestion boundary.
- Agents receive capabilities through a controlled tool gateway rather than unrestricted production access.
- Automated code remediation must pass tests/staging/policy gates before production.

## Planned service boundaries
1. Natural-language router/orchestrator
2. Consent and policy engine
3. Life Map / goals / tasks
4. Learning engine
5. Legal research retrieval with jurisdiction/effective-date/citations
6. Financial recovery workflows
7. Trauma-informed reflection and wellness support
8. Document/PDF ingestion and retrieval
9. Voice streaming adapters
10. Audit, privacy, security and observability
