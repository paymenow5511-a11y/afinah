Make Afinah your own

Install in Android Chrome using ⋮ → Add to Home screen → Install. A secure HTTPS address is required. Once opened online, Afinah can work offline.

Tasks and notes stay in this browser on this device. They are not synced to an account. Clearing browser data removes them. Export a backup regularly.

Gentle reminders

Set a due date, time, and “Remind me” on a task. Afinah shows due reminders while the app is open. Android may pause the app in the background.

Reminders when Afinah is closed

Export reminder tasks to a calendar, then import the .ics file into Google Calendar on the web (Settings → Import & export). Check that the imported events have notifications enabled. Your calendar handles alerts after import; later Afinah edits do not sync automatically. Re-importing may create duplicates.

Back up your space

Restore replaces this device's tasks and notes after confirmation. Your backup contains personal information; keep it somewhere private.
