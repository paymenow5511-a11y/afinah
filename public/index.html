One-time Microsoft setup

Microsoft requires an app registration before Afinah can connect. This setup is done once; you then sign in normally.

  1. Open the Microsoft Entra admin center. Sign in with an account allowed to register applications.
  2. Go to Entra ID → App registrations → New registration. Name it Afinah. Choose support for organizational and personal Microsoft accounts.
  3. Under Authentication → Add a platform → Single-page application, add this redirect URI: . Keep implicit grant disabled. No client secret is needed.
  4. Under API permissions → Add a permission → Microsoft Graph → Delegated permissions, add Calendars.ReadBasic.
  5. Copy the Application (client) ID from Overview into the field below, save it, then choose Connect Outlook.

If Microsoft says you cannot create an app, your Microsoft administrator needs to register it. This setup is separate from connecting Outlook to ChatGPT.

The application ID is a public identifier. Never enter a password, client secret, or access token here.

Calendar data goes directly between this device and Microsoft. A saved copy stays on this device, separate from task backups. Disconnect removes that copy and Afinah’s local Microsoft session; it does not sign you out of Outlook elsewhere or revoke the consent in your Microsoft account.

Make Afinah your own

Install in Android Chrome using ⋮ → Add to Home screen → Install. A secure HTTPS address is required. Once opened online, Afinah can work offline.

Tasks and notes stay in this browser on this device. They are not synced to an account. Clearing browser data removes them. Export a backup regularly.

Gentle reminders

Set a due date, time, and “Remind me” on a task. Afinah shows due reminders while the app is open. Android may pause the app in the background.

Reminders when Afinah is closed

Export reminder tasks to a calendar. In Outlook on the web, choose Add calendar → Upload from file, then import the .ics file. Check that the imported events have notifications enabled. Your calendar handles alerts after import; later Afinah edits do not sync automatically. Re-importing may create duplicates.

Back up your space

Restore replaces this device's tasks and notes after confirmation. Your backup contains personal information; keep it somewhere private.
